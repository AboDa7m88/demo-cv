# Demo CV — Project Plan

**Goal:** Build a simple personal CV/portfolio page for myself using Angular, styled with Bootstrap. No backend, just local data.

### Sections I want on the page:
* **Header** — name, title, short tagline, contact info
* **About** — a short bio
* **Skills** — list of skills, maybe shown as badges
* **Experience** — past roles, timeline style
* **Projects** — a few project cards with short descriptions

### How I'll organize it:
* A shared data file that holds all my skills, experience, and projects
* Separate components for each section
* Everything gets pulled together into one page
